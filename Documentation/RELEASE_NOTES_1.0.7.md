# 知行 1.0.7

## 菜单栏概览

- 设置新增「菜单栏概览」：倒数日、使命进度、今日任务三个独立开关，可同时打开，各自占用一个 `NSStatusItem`。
- 旧版本升级后默认只保留倒数日；关闭某一项会销毁对应图标，刷新时不会重复创建。
- 倒数日显示日历图标与最近事件剩余天数；今日任务使用清单图标，并按现有「今日任务」语义统计未完成数量（含今日到期与逾期，不含收件箱）。
- 使命进度改为单色模板水位球：圆形容器从底部向上注水，跟随系统菜单栏前景色；使命颜色仍只用于使命卡和编辑器。菜单栏 18–22pt 使用水位球；更小尺寸回退为同色圆环百分比。旁白继续读出进度百分比。
- 可在设置中选择要显示的使命；被删除后会清空选择并显示空状态。点击各图标可打开对应分区。跨日刷新会同步日历、任务与使命指标。
