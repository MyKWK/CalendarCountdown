# 知行 1.0.4

## 设计系统

- 应用品牌色固定为“钛灰 · 冰川青”，不再提供全局主题色或任意取色器；浅色、深色和跟随系统外观继续保留。
- 使命拥有独立的 12 色 Apple 风格动态色板，颜色用于使命图标、卡片标识、进度、任务归属标签与 Widget。
- 启用新的冰川青与钛灰应用图标，使 Dock、访达、DMG 与应用内设计语言保持一致。

## 使命与效率

- 新建使命自动选择当前使用最少的身份色，也可以在“图标与颜色”中自行指定。
- 旧版十六进制使命颜色会自动映射到最接近的新色板，不清空既有使命数据。
- 完善使命编辑、删除、任务新建与已有任务关联入口，并增加应用内和全局快捷键支持。
- 设置中保留页面外观与可访问性约束下的主窗口玻璃效果。

## 验证边界

- macOS App、Widget、CLI、Core 与 Persistence 在本机完成构建和单元测试；iPhone/iPad 与移动 Widget 完成模拟器编译验证。
- 本发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证或真实 CloudKit 跨设备验收。
