# 知行 1.0.17

## Codex 风格主窗口

- 主窗口启用真正的窗口级模糊玻璃，以冷白雾面承载正文、冷蓝半透明材质承载侧栏。
- 侧栏采用与 Codex 同类的信息层级：品牌栏、按需展开的搜索、当前模块新建入口、工作区导航与底部工具区。
- 主区移除醒目的黑色新建按钮；主要操作回到侧栏，标题栏只保留低干扰的数据与投影菜单。
- 任务、习惯与使命由白色卡片墙改为无底色安静行，默认只显示极弱分隔，悬停时才出现层级反馈。
- 保留四个一级模块、任务完成/编辑、使命展开/编辑、iCloud 控制、快捷键及数据语义。

## 通透程度与无障碍

- 默认通透度调整为与当前 Codex 相近的 42%，设置中的滑块会同时调节窗口雾化和各层表面。
- 背景只以模糊后的材质参与混合，不显示未经处理的桌面内容。
- macOS 开启“降低透明度”或“增强对比度”时自动回退为实色高对比界面。

## 版本与边界

- 版本 `1.0.17`，构建号 `19`。
- 本机安装只替换 `/Applications/知行.app`，不改动已有任务、使命、打卡、日历、偏好设置或数据库。
- 本机 ad-hoc 签名与模拟器构建不等同于 Developer ID、公证、真机或 CloudKit 跨设备验收。
