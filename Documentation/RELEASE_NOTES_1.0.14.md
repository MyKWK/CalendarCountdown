# 知行 1.0.14

## Codex 审美重构

本版不再只调整字体或局部玻璃，而是重构 macOS 主窗口的信息架构和视觉材料，使界面与 Codex 的安静、扁平、中性审美处于同一体系。

- 侧栏收敛为四个业务入口，搜索置顶，iCloud、刷新与设置固定到底部。
- 内容区增加固定顶部动作栏；“新建”成为唯一主操作，导入、导出与投影收进溢出菜单。
- 移除青绿色全窗渐变、大面积玻璃、卡片阴影和非必要胶囊，改用近黑 / 暖灰画布与细分隔线。
- 页面标题、数量摘要、空状态、任务卡片、使命卡片和设置窗口统一采用更接近 Codex 的轻量层级。
- 保留四个一级模块、任务完成尾迹、可访问性标识、浅色 / 深色和系统辅助功能适配。
- 修复任务页布局状态写回与窗口玻璃探针共同触发的 AppKit 约束更新递归，避免页面切换时反复意外退出。

## 版本与边界

- 版本 `1.0.14`，构建号 `15`。
- 不修改数据模型、数据库 schema、CloudKit / EventKit / CLI 语义。
- 发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证、真机或 CloudKit 跨设备验收。
