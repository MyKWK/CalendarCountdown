# 知行 1.0.15 展示层收敛

## 目标

工作量数值仍用于内部任务评估、使命进度和数据计算，但不在任务列表或使命关联任务列表中显示“点”这一计量单位。

## 规则

- 普通任务列表不展示工作量数值或“点”。
- 使命关联任务列表不展示工作量数值或“点”。
- 新建任务、编辑任务中的“工作量”选择器保留，用于内部评估输入。
- 使命标题行双击负责展开/收起，并使用轻微弹性布局动画；关联任务卡片双击直接打开编辑。
- 使命标题行与关联任务卡片分离点击命中区域，避免任务操作误触发使命折叠。
- 数据模型、使命加权进度、同步和 CLI 合同不变。

## 验收边界

- 通过 macOS 测试、iOS Simulator 编译、Universal DMG、安装、签名和 SHA-256 校验。
- 本地 ad-hoc 安装不代表 Developer ID、公证、真机或 CloudKit 跨设备验收。
