# 知行 1.0.12

## Codex 风格的侧边栏与任务视觉升级

本版将 macOS 主界面的操作层级重新收纳到左侧边栏，保留四个核心业务模块，同时让主内容区更安静、更专注。

- 移除主界面顶部的新建、整理、搜索和设置操作，仅保留系统窗口控件和当前页标题。
- 左侧边栏新增搜索，并按“工作区”“快速操作”“数据与系统”“偏好设置”分组，新建、刷新、导入导出、投影和设置都从侧边栏进入。
- iCloud 同步只保留左下角的唯一入口，不再在主界面中重复展示。
- 任务的未完成与已完成区之间增加留白、极轻虚线和弱化层级，保持信息连续性。
- 使命标签从高饱和胶囊改为暗色矿物色系的小圆角标记；文字与图标采用自适应钛灰色，背景保留使命身份色。
- 使命编辑器保留行内图标选择器，并将颜色名称统一为低饱和、暗色系命名。
- 玻璃效果采用应用内部的局部材质和分层，不开启会损害可读性的整窗穿透。

## 版本与边界

- 版本 `1.0.12`，构建号 `13`。
- 不修改数据模型、数据库 schema、CloudKit / EventKit / CLI 语义，也不新增第五个一级入口。
- 发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证、真机或 CloudKit 跨设备验收。
