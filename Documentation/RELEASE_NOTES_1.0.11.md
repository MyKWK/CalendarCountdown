# 知行 1.0.11

## Apple Glass 视觉升级

把主窗口从功能完整但偏工具化的界面，升级为安静、精密、可信赖的 Apple 原生个人执行系统。本版不是全窗穿透玻璃，也不用大面积彩色卡片堆层级。

- 统一设计系统：间距、圆角、材质、动效和状态反馈集中在 `ZhixingDesignSystem`，四个模块共用同一套视觉语法。
- 侧栏选中改为单层柔和玻璃胶囊；未选中图标与数量降低对比。底部只显示极轻量的同步摘要，不是第二个开关。
- 工具栏主操作只保留「新建」，随当前模块变化。导入、导出、刷新和系统投影收进「整理」菜单。iCloud 使用小型状态胶囊，显示仅本机 / 已开启（待首次同步） / 同步中 / 已同步 / 失败；设置按钮保持独立。仅在真实同步进行中显示「同步中」，有 lastFetch/lastSend 后才显示「已同步」。
- 倒数日以最近一项为焦点行，其余保持紧凑列表；日历色改为细标识，收藏与更多操作在悬停时更清楚。
- 任务清单改为紧凑横向条形卡片：未完成在前，完成后以 fade/move 沉入底部已完成尾迹，并按视口位置、hover 与焦点恢复可读度。
- 使命卡片改为中性底 + 小面积身份色；进度是主数据。管理动作收进 overflow/context menu，双击折叠、添加任务、关联已有任务和完成使命仍可用。
- 打卡以今日状态和连续性为重心；空状态提供「新建打卡」。
- 新建/编辑 Sheet 统一为标题区、内容分组和固定底部操作：取消为次级，保存/创建为唯一主按钮。成功提示使用底部悬浮玻璃胶囊；错误仍用显式 alert。

## 版本与边界

- 版本 `1.0.11`，构建号 `12`。全窗穿透玻璃保持关闭（`WindowGlassAppearance.userFacingEnabled = false`）。
- 不修改数据模型、数据库 schema、CloudKit / EventKit / CLI 语义，也不新增第五个一级入口。
- 本发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证或真实 CloudKit 跨设备验收。完整本地发布与 `/Applications/知行.app` 替换在 Codex 独立验收通过后执行。
