# DevEco Studio 模拟器与验证手册

## 1. 三类证据不要混淆

| 证据 | 可以证明 | 不能证明 |
|---|---|---|
| ArkUI Previewer | 基础布局/状态预览 | 完整系统 API、网络、数据库、权限、安装包 |
| DevEco Phone emulator | 构建、安装、导航、基础交互、部分调试工具 | 真机权限、后台行为、性能、硬件能力、商店签名 |
| 已签名真机 | 证书/Profile、权限、系统集成与设备差异 | 生产云服务/商店审核，除非另有证据 |

官方开发入门页指出，模拟器和预览器调试不需要签名；真机调试必须对 HAP 配置签名。把这两类环境的日志、截图和产物目录分开保存。

## 2. IDE 图形界面：首次创建 Phone 模拟器

1. 安装并打开 DevEco Studio，使用与项目目标 API 相匹配的 SDK/镜像；不要把“最新版”与仓颉公测插件默认视为兼容。
2. 登录华为开发者账号。官方仓颉指引提示首次使用 Device Manager 需要登录且开通模拟器权限。
3. 打开 **Tools > Device Manager**，在 **Local Emulator** 选择 **New Emulator**。
4. 选择 Phone 设备模板；如果出现 `Download the system image first`，下载匹配系统镜像后再创建实例。记录 image 名称、API、设备模板、内存、存储和创建日期。
5. 启动实例，在设备选择栏选择它并运行应用。对仓颉工程，官方指引的范围是 Phone 运行；不要在未验证前承诺 tablet、PC、wearable 或多设备流转支持。
6. 最少做四项检查：首次安装冷启动、关闭后再启动、断点/日志、横竖屏（若产品需要）。保留无个人数据的截图或日志摘要。

官方仓颉入门指引列出的默认位置仅供定位排错，不应硬编码或提交：macOS 模拟器实例默认 `~/.Huawei/Emulator/deployed`，SDK/image 默认 `~/Library/Huawei/Sdk`。实际位置以本机 Device Manager 配置为准。

## 3. 命令行模拟器（可选，先以 IDE 成功为前提）

官方最新命令行文档说明 Emulator CLI 随 DevEco Studio/Command Line Tools 提供，macOS 可把 `{DevEco Studio 安装目录}/tools/emulator` 加到 `PATH`。支持查询镜像、下载镜像、创建/启动/关闭实例、截屏、GPS、电池、传感器和 UI 操作等。

第一次接入自动化时，不要复制网上的固定路径或 API 名称。先在已安装 IDE 的机器上：

```zsh
# 将 <DevEco Studio 安装目录> 换成实际值；仅当前 shell 生效。
export PATH="<DevEco Studio 安装目录>/tools/emulator:$PATH"
Emulator -help
Emulator -version
```

然后以该命令输出和当前官方文档为准，记录实际支持的子命令。官方文档给出的创建模型要求名称、设备类型、系统镜像版本，且可设实例路径、镜像根目录、屏幕、存储、内存、热启动等参数；这些参数随 DevEco 版本变动，不能在仓库中写死。

## 4. H1 验收表

| 编号 | 验收项 | 所需证据 | 失败时先查 |
|---|---|---|---|
| E1 | DevEco 能创建 ArkTS Empty Ability | project 创建记录、成功 build | SDK manager、网络/代理、API 镜像 |
| E2 | Phone 模拟器能冷启动 | 设备状态、应用首屏 | image/API 与 app compatibility |
| E3 | Debugger/日志可用 | 一个断点和无敏感日志片段 | Device Manager、调试配置 |
| E4 | 关闭重启后本地状态符合预期 | 无隐私 fixture 的前后记录 | RDB transaction、data sandbox |
| E5 | 仓颉（可选）Empty Ability 可同样通过 | 版本配对记录、build/deploy/debug | 公测权限、插件-IDE 匹配、Phone 支持范围 |
| E6 | 自动化（可选）能启动既有实例 | CLI `-help`、启动/截屏日志 | CLI 版本、实例/镜像路径 |

E1–E4 通过才允许创建产品 `harmonyos/` 工程；E5 仅决定是否可以启动仓颉试验，不决定 ArkTS 产品路线。任何 Emulator 成功都不等于云同步、日历/提醒权限或应用市场发布通过。

## 5. 设备与数据安全

- 使用虚构 fixture；不要把现有 Apple 日历、CloudKit 数据、个人任务导入模拟器。
- 每个调试 bundle name 与生产候选分开，debug/release 安装不要混用同一环境数据。
- 模拟器快照可能保留登录状态和测试数据。移交/删除实例前按团队安全要求登出、清除数据；不要把其目录纳入 Git 或备份到公共位置。
- `*.p12`、`.cer`、`.p7b`、Profile、keystore、账号 token 和设备日志中可能包含敏感信息。将它们留在受控凭证存储，不提交、不贴进 issue、不写进本知识库。
