# 知行 1.0.16

## 编辑与创建

- 任务清单中双击一条任务会直接打开该任务的编辑框；完成按钮和“跳过”仍保持单击操作。
- 当前模块下按下 ⌘N 会打开该模块的新建界面：倒数日、任务、使命或打卡。
- 快捷操作菜单里的 ⇧⌘D / ⇧⌘N / ⇧⌘M / ⇧⌘H 仍然可以跳到对应模块并新建。
- 不修改任务数据模型、使命进度、同步或 CLI 语义。

## 外观

- 设置 → 外观中可用滑块整体调节通透程度，拖动时主窗口即时预览。
- 默认侧栏比正文更透、正文更实；各区域一起变，相对层次保持不变。
- 不开启桌面壁纸穿透。系统“降低透明度”开启时退回实色。

## 版本与边界

- 版本 `1.0.16`，构建号 `18`。
- 本机安装只替换 `/Applications/知行.app`，不改动 App Group 数据库、日历或用户数据。
- 发行包为本机 ad-hoc 签名，不等同于 Developer ID 签名、Apple 公证、真机或 CloudKit 跨设备验收。
