# 知行 1.0.14 Codex 审美重构

## 目标

让 macOS 主窗口与 Codex 使用同一种视觉语法：中性黑灰画布、扁平分栏、克制的控件、明确的单一主操作，以及依靠留白和字级建立的信息层次。

这里的“复刻”指审美与交互层级一致，不复制 OpenAI 商标、专有图标、文案或未公开实现。知行仍保留倒数日、任务清单、使命清单、打卡四个业务入口与既有数据语义。

## 主要变化

- 取消全窗青绿渐变、彩色高光和大面积玻璃，改为浅色暖灰 / 深色近黑的中性双画布。
- 侧栏仅保留四个一级入口；搜索固定在顶部，iCloud、刷新和设置收在底部。
- 新建成为内容区唯一高权重按钮；导入、导出与系统投影进入右上角溢出菜单。
- 页面标题与数量摘要进入固定顶部栏，内容列表不再重复大标题。
- 普通任务行、倒数行和标签降低边框、阴影与胶囊密度；悬停时才提高容器可见度。
- 使命和习惯继续保留身份色，但颜色只用于图标、细标记、进度和状态。
- 空状态改成 Codex 式的小图标、紧凑标题、短说明和单一动作。
- 窗口采用透明标题栏与全尺寸内容，让侧栏和内容画布从窗口顶部连续铺开。

## 保留的产品合同

- 四个一级入口及其快捷键、搜索、新建、编辑、完成、跳过、归档与删除行为不变。
- `mac-icloud-sync-control` 与 `mac-settings-button` 仍是独立控件。
- EventKit、CloudKit、数据库 schema、CLI、系统投影与同步语义不变。
- 完成任务尾迹仍可通过滚动、悬停、键盘与辅助功能焦点恢复可读性。
- 继续支持浅色、深色、增加对比度、降低透明度与降低动态效果。

## 验收边界

- 必须通过 macOS 测试、iOS Simulator 编译、Universal DMG、归档、安装、签名、版本与架构校验。
- 必须检查真实安装版的主窗口、四个模块和设置入口。
- 本地 ad-hoc 安装不代表 Developer ID、公证、真机、App Store 或 CloudKit 跨设备验收。
