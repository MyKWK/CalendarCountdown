# 知行 1.0.13

## Codex 风格的轻量排版

本版在 1.0.12 的分组侧边栏、局部玻璃与任务分隔基础上，统一调整 macOS 与 iOS 的文字层级，使界面更接近 Codex 的冷静、轻盈和低对比度质感。

- 新增集中式冷钛灰文字色阶，普通文字避免纯黑或纯白，并适配浅色、深色与“增加对比度”辅助功能。
- 侧栏品牌、分组、业务入口与操作入口统一缩小字级并减轻字重；选中项最多使用 medium。
- 页面、任务、使命、打卡、倒数与空状态标题从普遍 semibold 调整为更克制的 medium 层级。
- 设置窗口、菜单栏概览与使命编辑器同步采用同一排版和辅助文字色阶。
- 保留四个一级模块、Codex 风格分组侧栏、局部玻璃、暗色使命标签、任务完成分隔以及状态强调色。

## 版本与边界

- 版本 `1.0.13`，构建号 `14`。
- 不修改数据模型、数据库 schema、CloudKit / EventKit / CLI 语义。
- 发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证、真机或 CloudKit 跨设备验收。
