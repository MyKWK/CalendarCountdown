# 知行 1.0.19

## 可感知的背景雾化

- 修正了 1.0.18 三档背景模糊过于接近的问题。
- 三档保持相同的透明度语义，但新增独立的背景雾化半径：轻柔 4pt、标准 14pt、浓雾 30pt。
- 模糊强度以窗口级高斯背景滤镜实现，选择后立即更新主窗口，不再依赖系统材质之间难以辨认的细微差异。

## 快捷日期选择

- 任务、使命和重要日的日期输入提供“今天”“明天”“下周一”“日历选择”四个快捷入口；带时分的输入保留原来的具体时间选择。
- 仅点按“日历选择”才会打开日历。新日历以更大的独立面板展示连续月份，支持上下滚动浏览并选择日期。

## 版本与边界

- 版本 `1.0.19`，构建号 `21`。
- 本地发布流程覆盖 macOS 测试、iOS Simulator 编译、Universal DMG、签名、安装替换与校验和；不等同于 iOS 真机、CloudKit 跨设备、Developer ID 或公证验收。
