# 日历倒数 1.0.2

## 修复

- 修复主应用和顶部菜单栏跨过午夜后仍显示前一天倒数、必须手动刷新的问题。
- 应用常驻时会在本地时间下一次午夜自动刷新 Apple 日历事件、倒数卡片、顶部菜单栏和小组件快照。
- 电脑在午夜休眠时，会在唤醒后补刷新；系统日期、时钟或时区变化，以及应用重新激活时也会检查是否已经跨日。
- 同一日内的多个系统通知会被合并，不会重复执行跨日刷新。
- 修复系统跨日通知从后台队列投递时触发 MainActor 断言、导致应用退出的问题。
- 将默认主题“AI 蓝”改为自动驾驶状态标志灯的屏幕近似色 `#00E5D4`，并改善明亮主题色上的选中勾对比度。
- 确认多处“随机外框”实为 SwiftUI 默认焦点环随焦点迁移；统一关闭按钮、工具栏、侧栏动作、事件动作、菜单栏动作及主题色块的额外外层焦点效果，输入控件仍保留原生焦点提示。

## 升级说明

- 若桌面仍放置标识升级前的旧版小组件，系统重启后旧缓存失效会显示为空白；请移除该旧实例，并从小组件图库重新添加当前版本的“日历倒数”。

## 验证

- 新增午夜只刷新一次及睡眠跨多日后补刷新的回归测试。
- macOS App、Widget、CLI 与 17 个单元测试通过本地构建验证。
