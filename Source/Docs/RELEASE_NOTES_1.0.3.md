# 知行 1.0.3

## 新增

- 增加任务、使命与习惯的工作区，并将倒数、任务、使命、习惯整合为四个主导航入口。
- 增加本机优先的 SQLite 工作区、应用内 Broker、系统投影与诊断日志基础能力。
- 增加 iCloud/CloudKit 同步的状态建模与本地数据隔离基础；真实跨设备同步仍要求带 iCloud 容器权限的 Apple 开发签名。

## 体验改进

- iCloud 同步改为独立状态控件：未开启时显示“仅本机”，开启后显示强调色和勾选状态。
- 将颜色盘从工具栏移入独立的“设置”窗口；设置窗口采用可扩展分类结构，当前提供“外观与主题”。
- 如果安装包不具备 iCloud 容器权限，开启同步会明确说明原因并保持本机模式，不再无提示地回退。

## 验证边界

- macOS App、Widget、CLI 与 Core/Persistence 单元测试在本机完成构建和测试。
- 本发行包为 ad-hoc 本机签名；未具备 Apple Development 或 Developer ID 证书，不能作为 CloudKit 跨设备同步或 Apple 公证发行的验收依据。
