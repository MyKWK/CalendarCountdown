# 知行 1.0.12

## Codex 风格的侧边栏与任务视觉升级

- 主窗口顶部不再放置操作菜单；新建、刷新、导入导出、系统投影和设置按类别进入左侧边栏。
- 左侧边栏增加内联搜索，保留四个核心业务模块，iCloud 同步仅在左下角显示。
- 任务未完成与已完成区增加间距和轻微虚线，使命标签改为低饱和暗色矿物色系与钛灰文字。
- 局部玻璃材质、卡片分层和深色模式均经重新校准，不开启整窗穿透。

## 版本与边界

- 版本 `1.0.12`，构建号 `13`。
- 本发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证、真机或 CloudKit 跨设备验收。
