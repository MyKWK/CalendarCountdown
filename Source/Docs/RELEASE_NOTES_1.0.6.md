# 知行 1.0.6

## 使命编辑

- 新建和编辑共用同一份检查器：标题、名称字段、底部取消/保存始终留在可见工作区；内容区可滚动，窄窗口和大字体时不会裁切主要操作。
- 颜色是独立字段，使用现有 12 个 Apple 风格使命色，带名称的圆形色板、选中态和无障碍标签；不再藏在图标网格里。
- 图标选择改为可折叠、内部滚动，避免挤压名称、颜色、说明和目标。
- 选色会实时预览，保存后立即更新使命卡、进度条和菜单栏使命球；旧十六进制颜色仍映射到最接近的色板。固定的钛灰 · 冰川青应用主题不受影响。

## 状态栏与授权

- 菜单栏状态项用当前使命色球标识身份，弹出层同时列出使命进度；关闭主窗口后状态栏仍保持可用。
- 日历权限被拒绝后会引导到系统设置；在设置中恢复授权后，回到知行会重新读取倒数，而不会卡在旧的未授权状态。

## 验证边界

- macOS App、Widget、CLI、Core 与 Persistence 在本机完成构建和单元测试；iPhone/iPad 与移动 Widget 完成模拟器编译验证。
- 本发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证或真实 CloudKit 跨设备验收。
