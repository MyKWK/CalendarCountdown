# 知行 1.0.11

## Apple Glass 视觉升级

把主窗口从功能完整但偏工具化的界面，升级为安静、精密、可信赖的 Apple 原生个人执行系统。本版不是全窗穿透玻璃，也不用大面积彩色卡片堆层级。

- 任务清单为紧凑条形卡片，完成后沉入视口驱动的已完成尾迹。
- iCloud 使用小型状态胶囊，显示仅本机 / 已开启（待首次同步） / 同步中 / 已同步 / 失败；设置保持独立。仅在真实同步进行中显示「同步中」。
- 空状态、编辑 Sheet 和成功/失败反馈使用同一套组件。全窗穿透玻璃保持关闭。

## 版本与边界

- 版本 `1.0.11`，构建号 `12`。
- 本发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证或真实 CloudKit 跨设备验收。
