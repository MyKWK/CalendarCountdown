# 知行 1.0.13

## Codex 风格的轻量排版

- 新增自适应浅色、深色与“增加对比度”的冷钛灰文字色阶，普通文字避免纯黑或纯白。
- 侧栏、页面标题、任务、使命、打卡、倒数与空状态统一减小字级、降低字重，选中项最多 medium。
- 设置窗口、菜单栏概览与使命编辑器同步采用共享排版 token；状态色和输入控件保持清晰。
- 保留分组侧边栏、局部玻璃、暗色使命标签、任务完成分隔和四个一级模块。
