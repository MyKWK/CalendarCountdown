# 知行 1.0.20

## 连续背景雾化

- 将“轻柔／标准／浓雾”三档替换为 2–60pt、步进 1pt 的连续背景模糊滑块，透明度继续独立控制。
- 修正 1.0.19 将滤镜挂在空透明层上、切换设置却没有可见变化的问题；现在直接柔化承载实时系统玻璃的内容层。
- 自动迁移旧三档偏好：轻柔为 4pt、标准为 18pt、浓雾为 42pt。

## Codex 式窗口标题栏

- 主窗口和设置窗口使用紧凑的原生侧边栏按钮，放在交通灯右侧，不再占据侧边栏顶部的大块空间。
- 收起与展开继续使用系统 `NSSplitViewController` 动作，并保留辅助功能标签。

## 快捷日期选择

- 任务、使命和重要日支持“今天”“明天”“下周一”和滚动日历；日期快捷项会保留已有时分。
