# 知行 1.0.14

## Codex 审美重构

- macOS 主窗口改为近黑 / 暖灰双画布，移除全窗渐变、大面积玻璃和卡片阴影。
- 侧栏仅保留四个一级入口；搜索置顶，iCloud、刷新与设置固定到底部。
- 内容区使用固定标题栏，“新建”成为唯一主操作，导入、导出与投影收进溢出菜单。
- 列表、使命、标签与空状态统一降低边框、胶囊与颜色密度，并保留悬停和辅助功能反馈。
- 设置窗口同步采用中性侧栏与内容底色。

## 版本与边界

- 版本 `1.0.14`，构建号 `15`。
- 本发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证、真机或 CloudKit 跨设备验收。
