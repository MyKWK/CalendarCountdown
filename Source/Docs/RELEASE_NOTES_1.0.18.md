# 知行 1.0.18

## 独立背景模糊选择

- 外观设置新增“背景模糊”三档选择：轻柔、标准、浓雾。
- 背景模糊与透明度分离：透明度控制背景显露多少；模糊档位控制显露的背景细节被柔化多少。
- 三档直接切换窗口底层的 macOS 系统视觉材质，立即作用于主窗口，并会保存至下次启动。
- 透明度设为任意值时都可选择模糊档位；开启 macOS“降低透明度”时，为保证可读性统一回退为实色。
