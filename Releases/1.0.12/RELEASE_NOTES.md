# 知行 1.0.12

## Codex 风格的侧边栏与任务视觉升级

- 主窗口顶部不再放置操作菜单；所有操作与设置按“工作区”“快速操作”“数据与系统”“偏好设置”分组进入左侧边栏。
- 搜索收入侧边栏，iCloud 同步仅保留左下角的唯一入口。
- 任务的未完成与已完成区增加留白和极轻虚线，使命标签改为低饱和暗色矿物色系、钛灰文字和小圆角造型。
- 使命编辑器提供行内图标选择，局部玻璃材质和卡片分层在浅色、深色模式下都保持可读。
