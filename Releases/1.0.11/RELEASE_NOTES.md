# 知行 1.0.11

## Apple Glass 视觉升级

- 四个核心模块统一使用新的间距、圆角、材质、动效和状态反馈系统，整体层级更安静、精密，并保持 Apple 原生产品感。
- 侧栏、工具栏、状态提示、空状态与新建/编辑面板统一为轻量玻璃语法；主工具栏只保留当前模块的「新建」主操作。
- 任务改为紧凑横向条形卡片。未完成任务在前，完成任务沉入底部尾迹，并按深度逐渐变暗、变淡；滚动进入视口、悬停、键盘聚焦或辅助功能读取时会恢复可读度。
- 倒数日强化最近一项，使命改为中性卡片搭配细身份色，打卡突出今日状态与连续性，减少大面积彩色卡片造成的廉价感。
- iCloud 状态区分仅本机、已开启、同步中、已同步与失败，避免把“已启用但尚未产生同步时间”误报为正在同步。
