# 知行 1.0.16

## 编辑与创建

- 任务清单中双击一条任务会直接打开该任务的编辑框；完成按钮和“跳过”仍保持单击操作。
- 当前模块下按下 ⌘N 会打开该模块的新建界面：倒数日、任务、使命或打卡。
- 快捷操作菜单里的 ⇧⌘D / ⇧⌘N / ⇧⌘M / ⇧⌘H 仍然可以跳到对应模块并新建。
- 不修改任务数据模型、使命进度、同步或 CLI 语义。
- 设置 → 外观中可用滑块整体调节通透程度；侧栏默认比正文更透，相对层次保持不变。
- 不开启桌面壁纸穿透。

## 本地交付

- 版本：`1.0.16`，构建号：`18`。
- 产物：`CalendarCountdown-1.0.16-macos-universal.dmg`。
- 本机安装只替换 `/Applications/知行.app`，不改动 App Group 数据库、日历或用户数据。
- 本发行包为 ad-hoc 本机签名，不等同于 Developer ID 签名、Apple 公证、真机或 CloudKit 跨设备验收。
